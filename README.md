# لوحة الرد التلقائي (على Zernio)

اللوحة دي بتحدد **لكل فيديو** الرد بتاعه، و**Zernio** هو اللي بيرد على الكومنت ويبعت الرسالة ويتحقق من الفولو.
كل فيديو متفعّل في اللوحة = «Comment automation» واحدة على Zernio، واللوحة بتعملها وتعدّلها وتوقفها لوحدها لما تدوس **حفظ**.

```
كومنت على فيديو ──► Zernio (الـ automation بتاعة الفيديو)
                      ├─ الكومنت فيه كلمة التشغيل (أو أي كومنت لو مفيش كلمات)
                      ├─ التحقق من الفولو شغال؟
                      │     ├─ متابع      → الرسالة/اللينك
                      │     └─ مش متابع  → «اعمل فولو الأول» + زرار «عملت فولو» → يتأكد تاني
                      └─ بعد الرسالة → الرد على الكومنت
فيديو جاي (مجدول) ──► أول كومنت عليه يوصل /api/zernio-webhook
                      └─ وصفه فيه كلمة من «فيديوهات جاية» → اللوحة تعمله automation وترد على الكومنت ده
```

## استخدام اللوحة
1. افتح رابط الموقع واكتب كلمة السر (قيمة `VERIFY_TOKEN` في Vercel).
2. لكل فيديو: فعّل «رد تلقائي» واختار نوع الرد (لينك / رسالة / رسالة + لينك) ← **حفظ**. التغيير بيوصل Zernio فورًا.
3. «كلمات التشغيل والرد على الكومنت» تحت كل فيديو:
   - **كلمات التشغيل**: مفصولة بفاصلة. لو فاضية، أي كومنت بيشغّل الرد.
   - **الرد على الكومنت**: كل سطر رد مختلف وZernio بيختار واحد عشوائي (لحد 6). لو فاضي، بيستخدم الرد الافتراضي.
4. «التحقق من الفولو قبل الإرسال»: شغال افتراضيًا، وتقدر تقفله لأي فيديو.
5. «إعدادات عامة»: الرد الافتراضي، ونصوص رسالة الفولو وأزرارها، لكل الفيديوهات مرة واحدة.
6. **فيديو مجدول؟** من «فيديوهات مجدولة أو لسه جاية» اكتب كلمة أو هاشتاج هيكون في وصفه (مثلاً `#tool25`) والرد بتاعه.
7. الزرار اللي فوق بيوقف كل الردود مرة واحدة. الإيقاف بيعمل pause للـ automations على Zernio، فالأرقام بتفضل محفوظة.
8. تحت كل فيديو بتظهر أرقام Zernio: الكومنتات اللي اشتغل عليها، والرسايل، وضغطات اللينك، واللي عدّوا الفولو. ولو Zernio رفض إعدادات فيديو، الغلط بيظهر تحته بالأحمر.
9. أي automation تعملها على Zernio نفسه بتظهر في اللوحة وتقدر تعدّلها منها.

## الإعداد (مرة واحدة)
1. **Vercel → Environment Variables**:
   | الاسم | ليه |
   |---|---|
   | `VERIFY_TOKEN` | كلمة سر اللوحة |
   | `ZERNIO_API_KEY` | مفتاح Zernio API |
   | `ZERNIO_WEBHOOK_SECRET` | سر الـ webhook (أي نص طويل عشوائي) |
   | `ZERNIO_ACCOUNT_ID` / `ZERNIO_PROFILE_ID` | اختياري: لو مش موجودين، بيستخدم أول حساب انستجرام متوصل |
   | `BLOB_READ_WRITE_TOKEN` | بيتضاف لوحده لما تربط Blob store |
   | `IG_ACCESS_TOKEN` | اختياري: احتياطي لعرض البوستات لو Zernio مش متاح |
2. **Zernio → Webhooks**: ضيف `https://<موقعك>/api/zernio-webhook` لحدث `comment.received`، بنفس قيمة `ZERNIO_WEBHOOK_SECRET`. ده مطلوب بس لـ «فيديوهات جاية».
3. **انستجرام**: خلّي Zernio هو التطبيق الأساسي للرسايل (Settings ← Messages ← Connected tools، أو Conversation routing في Meta Business Suite). من غير الخطوة دي، زرار «عملت فولو» مش هيرد.
4. **وقّف flows بتاعة viaSocket** (Comment Reply v2 و Link Button v2) **في نفس الوقت** اللي تدوس فيه أول حفظ. لو الاتنين شغالين، الناس هتوصلها رسالتين.
5. افتح اللوحة ودوس **حفظ** مرة واحدة: الـ 12 فيديو القديمين بيتعملهم automations على Zernio.

`api/link.js` و `api/link-v2.js` و `api/should-reply.js` بتوع viaSocket لسه موجودين ومن غير تعديل، عشان لو احتجت ترجع. ممكن تمسحهم بعد ما تتأكد إن Zernio شغال.

## الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | اللوحة |
| `api/link.js` | viaSocket بيجيب منه لينك الفيديو. لو الفيديو مش متسجل، بيقرا وصفه ويدوّر على «فيديو جاي» مطابق |
| `api/admin.js` | API اللوحة (بكلمة السر). الحفظ بيعمل/يعدّل/يوقف الـ automations على Zernio |
| `api/zernio-webhook.js` | «فيديوهات جاية»: أول كومنت على فيديو جديد وصفه مطابق → automation جديدة |
| `lib/zernio.js` | التعامل مع Zernio API |
| `lib/sync.js` | تحويل إعدادات كل فيديو لـ automation، ومزامنة التغييرات بس |
| `lib/config.js` | حفظ الإعدادات على Vercel Blob + النصوص الافتراضية + لينكات الفيديوهات القديمة |
| `privacy.html` | صفحة الخصوصية |
