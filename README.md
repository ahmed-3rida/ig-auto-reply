# لوحة الرد التلقائي (على Zernio)

اللوحة دي بتحدد **لكل فيديو** الرد بتاعه، و**Zernio** هو اللي بيرد على الكومنت ويبعت الرسالة ويتحقق من الفولو.
كل فيديو متفعّل في اللوحة = «Comment automation» واحدة على Zernio، واللوحة بتعملها وتعدّلها وتوقفها لوحدها لما تدوس **حفظ**.

```
كومنت على فيديو ──► Zernio (الـ automation بتاعة الفيديو)
                      ├─ الكومنت فيه كلمة التشغيل (أو أي كومنت لو مفيش كلمات)
                      ├─ التحقق من الفولو شغال؟
                      │     ├─ متابع معروف  → الرسالة/اللينك
                      │     ├─ الحالة Unknown (أول كومنت) → Zernio يبعث رسالة التحقق تلقائيًا
                      │     └─ غير متابع معروف → الـ webhook يبعث رسالة أولى وزرار يعيد التحقق
                      └─ بعد الرسالة → الرد على الكومنت
فيديو جاي (مجدول) ──► أول كومنت عليه يوصل /api/zernio-webhook
                      └─ وصفه فيه كلمة من «فيديوهات جاية» → اللوحة تعمله automation وترد على الكومنت ده
```

## استخدام اللوحة
افتح رابط الموقع واكتب كلمة السر (قيمة `VERIFY_TOKEN` في Vercel). اللوحة فيها 5 تابات، وشغالة على الموبايل، وفيها وضع فاتح وغامق (الزرار اللي فوق).

- **الرئيسية**: الردود واللينكات والضغطات ونسبة اللي عملوا فولو بعد التحقق، يوم بيوم (7 / 14 / 30 يوم)، وأكتر الفيديوهات ضغطات.
- **الفيديوهات**: دوس على أي فيديو تفتح إعداداته:
  - نوع الرد (لينك / رسالة / رسالة + لينك)، واللينك، واسم الزرار، والتحقق من الفولو.
  - كلمات التشغيل (فاضي = أي كومنت)، و**«الكلمة في الخاص»**: لو حد بعت الكلمة في رسالة ياخد نفس الرد.
  - الرد على الكومنت (كل سطر رد عشوائي).
  - **معاينة** للرسايل بشكل محادثة إنستجرام.
  - **«رد على الكومنتات اللي فاتت»**: يرد على الكومنتات اللي ما اترد عليهاش (مفيش رد من الحساب تحتها، ولا Zernio بعتلها)، واللي عمرها أقل من 7 أيام.
- **جاية**: فيديوهات مجدولة. كلمة أو هاشتاج هيكون في الوصف + الرد.
- **الرسايل**: زرار يرد على الرسايل اللي فيها كلمة فيديو ومحدش رد عليها في آخر 24 ساعة (ومنها الـ Requests).
- **الأداء**: مشاهدات ووصول ولايكات وكومنتات وشير وحفظ ونسبة تفاعل ومتوسط المشاهدة لكل فيديو، والحساب يوم بيوم (من إنستجرام عن طريق Zernio).
- **الحالة**: فحص للنظام: Zernio والحساب، الـ webhook، آخر كومنت وصل، آخر رد اتبعت، الدوسات والرسايل اللي ضاعت لأن تطبيق تاني ماسك المحادثة (بأسماء أصحابها)، والفيديوهات اللي Zernio رفضها. النقطة اللي فوق جنب زرار الوضع بتنوّر أحمر لو فيه مشكلة.
- **الإعدادات**: النصوص العامة، وشكل أول رسالة، والرد على كل كومنت ولا أول كومنت بس، و«تحديث Zernio».

متنساش **حفظ** بعد أي تعديل (الشريط اللي تحت).

### التخزين
الإعدادات والأحداث في **Supabase**: جدول `app_config` (صف واحد) وجدول `events`، وعليهم RLS من غير policies، يعني السيرفر بس (بالمفتاح السري) يقدر يقرا ويكتب. أول مرة بعد ما تضيف Supabase، الإعدادات بتتنقل لوحدها من Blob، ولو Blob مش شغال بتتبني من Zernio. ولو Supabase وقع، اللوحة بتكمّل بآخر إعدادات سليمة، أو بتبنيها من Zernio.

### الإحصائيات
الأرقام من مصدرين: Zernio (اللي هو بعته، والضغطات على لينكاته) وسجل اللوحة نفسها (جدول `events` في Supabase). اللينكات اللي اللوحة بتبعتها بتعدّي على `/api/go` عشان الضغطة تتحسب، وبعدها بتفتح اللينك الحالي للفيديو.

## الإعداد (مرة واحدة)
1. **Vercel → Environment Variables**:
   | الاسم | ليه |
   |---|---|
   | `VERIFY_TOKEN` | كلمة سر اللوحة |
   | `ZERNIO_API_KEY` | مفتاح Zernio API |
   | `ZERNIO_WEBHOOK_SECRET` | سر الـ webhook (أي نص طويل عشوائي) |
   | `ZERNIO_ACCOUNT_ID` / `ZERNIO_PROFILE_ID` | اختياري: لو مش موجودين، بيستخدم أول حساب انستجرام متوصل |
   | `SUPABASE_URL` | رابط مشروع Supabase (قاعدة البيانات: الإعدادات + سجل الأحداث للإحصائيات) |
   | `SUPABASE_SECRET_KEY` | المفتاح السري لـ Supabase (أو `SUPABASE_SERVICE_ROLE_KEY`). للسيرفر بس — متحطوش في أي صفحة |
   | `BLOB_READ_WRITE_TOKEN` | قديم: بيتستخدم بس لو Supabase مش متضاف، ولنقل الإعدادات أول مرة |
   | `IG_ACCESS_TOKEN` | اختياري: احتياطي لعرض البوستات لو Zernio مش متاح |
2. **Zernio → Webhooks**: ضيف `https://<موقعك>/api/zernio-webhook` لحدثين: `comment.received` و `message.received`، بنفس قيمة `ZERNIO_WEBHOOK_SECRET`.
   - `comment.received`: لـ «فيديوهات جاية».
   - `message.received`: عشان زراير الرسايل القديمة اللي viaSocket بعتها («Link» و«Following») تفضل شغالة. الزرار بيتأكد من الفولو ويبعت اللينك، أو «اعمل فولو الأول».
3. **انستجرام**: خلّي Zernio هو التطبيق الأساسي للرسايل (Settings ← Messages ← Connected tools، أو Conversation routing في Meta Business Suite). من غير الخطوة دي، زرار «عملت فولو» مش هيرد.
4. **وقّف flows بتاعة viaSocket** (Comment Reply v2 و Link Button v2) **في نفس الوقت** اللي تدوس فيه أول حفظ. لو الاتنين شغالين، الناس هتوصلها رسالتين.
5. افتح اللوحة ودوس **حفظ** مرة واحدة: الـ 12 فيديو القديمين بيتعملهم automations على Zernio.

## الملفات
| الملف | الوظيفة |
|---|---|
| `index.html` | اللوحة |
| `api/admin.js` | API اللوحة (بكلمة السر): الإعدادات، البوستات، الحفظ والمزامنة مع Zernio، الإحصائيات، «اللي فاتت» |
| `api/zernio-webhook.js` | الكومنتات والرسايل اللحظية من Zernio |
| `api/go.js` | لينك متتبّع: يسجل الضغطة ويفتح لينك الفيديو |
| `lib/zernio.js` | التعامل مع Zernio API |
| `lib/sync.js` | تحويل إعدادات كل فيديو لـ automation على Zernio |
| `lib/respond.js` | بيقرر ويبعت الرد (الرسالة الأولى، اللينك، «اعمل فولو») |
| `lib/backfill.js` | «رد على الكومنتات/الرسايل اللي فاتت» |
| `lib/stats.js` و `lib/events.js` | إحصائيات الردود وسجل الأحداث |
| `lib/videostats.js` | أداء الفيديوهات (مشاهدات، وصول، تفاعل…) |
| `lib/health.js` | فحص «حالة النظام» |
| `lib/autokw.js` | كلمة الفيديو من الوصف («اكتب IDM في الكومنت») |
| `lib/config.js` | قراية وحفظ الإعدادات (Supabase، أو Blob قديمًا) + النصوص الافتراضية |
| `lib/db.js` | Supabase عن طريق REST |
| `lib/rebuild.js` | إعادة بناء الإعدادات من Zernio لو التخزين وقع |
| `privacy.html` | صفحة الخصوصية |
